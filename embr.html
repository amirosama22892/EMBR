About the Ampacity Calculator

The Three Phase Ampacity Calculator is an in-house tool for rating underground power cables. It implements the IEC 60287 / Neher–McGrath thermal-circuit methodology in a lightweight, zero-configuration browser tool, with three calculation engines covering the cable systems The Three Phase designs most often.

Calculation engines

  • MV Trefoil (15 / 25 / 35 kV) — 15, 25, and 35 kV TR-XLPE aluminium cables in touching trefoil, direct-buried or in conduit, at a user-selectable operating voltage. Full IEC 60287 loss model: skin and proximity effects, concentric-neutral shield loss, dielectric loss, and a two-zone dry-out external thermal resistance.
  • DC — solar and battery circuits, single conductors in conduit or direct burial, with a per-cable eccentric air-gap model for cables in conduit.
  • LVAC — low-voltage AC feeders with configurable phase topology (single-phase, split-phase, three-phase delta or wye).

Validation

The Ampacity Calculator is validated against two independent references: Cymcap 8.1 Rev 2 (a 62-scenario matrix; 58 of 58 valid scenarios within ±5%) and CIGRE Technical Brochure 880 (2022), the industry reference for verifying cable-rating tools. Against TB 880, the IEC 60287 engine reproduces the published reference values to their full precision, including the complete Case 4 (33 kV) current rating.

The Cymcap matrix was run at 35 kV. TB 880 contains no 15 kV or 25 kV single-core case, so the new libraries (Southwire SPEC 81102 / 81142) are instead cross-checked by an independent IEC 60287 recomputation that reproduces their full rating chain — R_ac, dielectric loss, T1/T3/T4, shield loss, and ampacity — term-by-term, run automatically in CI. Absolute validation against Cymcap at 15 kV / 25 kV is still pending, so treat those results as engineering estimates until that validation is complete.

Methodology: IEC 60287-1-1 and IEC 60287-2-1; Neher–McGrath (1957). CIGRE TB 880 is CIGRE copyright; the verification uses only the published numeric reference values.

Release Notes

v1.2

July 2026
  • Added 15 kV and 25 kV cable libraries (Southwire 100% IL TR-XLPE, 1/3 concentric neutral) alongside the existing 35 kV set; the cable list now calls out each voltage class.
  • Operating (line-to-line) voltage is now a selectable input and drives dielectric loss; it auto-fills to the cable class nominal and offers common presets.
  • Input validation blocks selecting a cable whose insulation class is below the operating voltage.
  • 15 kV / 25 kV ratings are verified by an independent IEC 60287 cross-check that reproduces the full rating chain term-by-term (run in CI).
  • 35 kV ratings are unchanged; absolute validation of 15 kV / 25 kV against Cymcap is still pending.

v1.1 — Patch

July 2026
  • Patched input verification bugs — out-of-range and malformed inputs are now rejected cleanly instead of breaking the tool.
  • Hardened the server: concurrent request handling, same-origin access, and a restricted set of served files.
  • Frontend robustness — results no longer flicker to stale values, and soil-temperature lookups surface real API errors.
  • Accessibility — the soil-preset dropdowns are now fully keyboard-operable.
  • New home-page carousel showing example cross-sections.

v1.0 — Production release

2026
  • New home page with Calculator, About, and Release Notes modules.
  • Independent verification against CIGRE TB 880 added — in-app report on the About page and an automated regression check in CI.
  • IEEE 442 soil-resistivity presets selectable directly on the Native Soil and Dry-Out Zone fields.
  • First production-ready release — the calculator leaves beta.

v0.5

June 2026
  • PDF report generation rebuilt on ReportLab; the report cross-section now matches the on-screen diagram 1:1.
  • Cross-section grade and depth view made consistent across MV, DC, and LVAC.
  • Browser tab title reflects the selected tool.

v0.3 — Validated release

May 2026
  • 58 of 58 valid scenarios validated against Cymcap 8.1 Rev 2.
  • NEC Table 8 DC resistance corrected to a true 20 °C reference; IEC daily loss factor; concentric-neutral shield loss with ICEA helical-lay correction.

v0.1 — Initial

March 2026
  • Initial three-engine implementation with simplified thermal models.
